Slack Integration Setup

Wire Slack as an I/O channel for the supervisor via chatbus.

November 2026 · Ref: PR #286

Architecture

Slack workspace #supervisor channel User posts message → Slack Events API → /webhook/slack (our server) → chatbus (supervisor/chat/in) → supervisor processes Supervisor replies → chatbus (supervisor/chat/out) → Slack connector polls → Slack Incoming Webhook → #supervisor channel

Slack is a thin transport layer. The Slack service (cmd/slack/) translates between Slack's API format and chatbus messages. No special Slack handling in the supervisor.

Setup Steps

Step 1: Create Slack App

Create new app → "From scratch" → Name: MCC Supervisor → Select your workspace.

Step 2: Incoming Webhooks (outbound)

App Settings → Incoming Webhooks → Toggle On → "Add New Webhook to Workspace" → Select #supervisor channel.

Copy the webhook URL. It looks like https://hooks.slack.com/services/T.../B.../xxx

Step 3: Event Subscriptions (inbound)

App Settings → Event Subscriptions → Toggle On.

  • Request URL: https://mushroomcloudcomputing.com/webhook/slack
  • Subscribe to bot events: message.channels

Slack will send a verification challenge to our endpoint. The handler responds automatically.

Step 4: OAuth & Permissions

App Settings → OAuth & Permissions → Add Bot Token Scopes:

  • chat:write — send messages
  • channels:history — read channel messages
  • channels:read — list channels

Install (or reinstall) to workspace. Copy the Bot User OAuth Token (xoxb-...).

Step 5: Get Signing Secret

App Settings → Basic Information → App Credentials → Copy Signing Secret.

Step 6: Submit Secrets

Submit these three values via the secrets form at /admin/secrets:

SLACK_WEBHOOK_URLThe incoming webhook URL from step 2
SLACK_BOT_TOKENThe xoxb-... token from step 4
SLACK_SIGNING_SECRETThe signing secret from step 5

Step 7: Invite Lisa

Workspace Settings → Invite People → Add Lisa → Add to #supervisor channel.

After Setup

Once secrets are submitted, merge PR #286 and deploy the Slack connector service. Messages in #supervisor will reach the supervisor via chatbus, and supervisor replies will appear in the channel.
