What Shipped

Major deliverables completed since the spore system was introduced (Nov 14):

Infrastructure & Platform

  • Spore tracking system — full data model, CLI, web views with filters, focus drill-down, blocked dependencies, seed/spore taxonomy. The canonical work tracker.
  • Activity viewer — real-time parsed JSONL transcripts showing what the supervisor is doing, with reasoning-only default filter.
  • Visual snapshot testing — Playwright + JSONL fixture harness for UI regression testing.
  • Taskmaster hygiene ticker — periodic spore health checks with dual chatbus + MCP delivery, nag dedup, cooldown.
  • Component-level health — recovery-first connection handling, liveness checks on resume.
  • Node version unification — all repos pinned to Node 22.
  • System architecture doc — comprehensive reference covering all services, communication planes, and agent types.

Voice & Audio

  • Voice WebSocket stability — heartbeat timeout triggers reconnect instead of permanent disconnect.
  • Audio distortion fix — cleared stale buffers on suspend/resume, wired web visibility events, fixed duration calculation.
  • TTS failure recovery — sends tts_end on failure to prevent client hang.
  • Mobile liveness check — reconnect and health check on resume from background.

Mobile

  • Supervisor dashboard — swipeable pager layout with activity, spores, and tasks tiles.
  • Auto-submit on idle — 8s timeout for mobile chat where Enter is unreliable.
  • EAS build fixed — vendored mcc-activity client for cloud build compatibility.

Web UI

  • Three-column supervisor layout — voice/chat/tasks with activity and spores tiles.
  • Spores tile — live WebSocket, grouped layout, filter buttons.
  • Screenshot requirement — all feature PRs must include screenshots.

Integrations

  • Linear integration — API connected, webhooks deployed with HMAC verification, schema mapped. Push sync and drift detection planned.
  • Slack connector — bidirectional chatbus bridge + multi-channel routing.
  • Email pipeline — email → mcc-notes transcription wired.
  • Auth token refresh — fixed em-dash crontab bug, sign-out UI added.

Key Decisions

  • Spores over Linear for tracking — local-first JSON with CLI, Linear for external visibility only.
  • GitHub CI as primary test runner — no full suites locally, targeted single-file only.
  • Taskmaster dual delivery — chatbus for logging, direct MCP channel POST for supervisor delivery.
  • Screenshots on feature PRs — mandatory for all UI-changing PRs.
  • Mobile auto-submit — 8s idle timeout, mobile-only, compensates for unreliable Enter key.
