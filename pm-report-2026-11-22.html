What shipped

Fixed distorted audio on app foregrounding

Users reported garbled audio when switching back to the app — both web and mobile. Root cause turned out to be three overlapping bugs:

  • The orchestrator's suspend/resume cycle never touched the audio engine. Stale nextPlayTime and buffered TTS chunks survived across background, causing garbled playback when new audio arrived.
  • Web had no visibilitychange → bus event wiring. The orchestrator listened for app:suspend/app:resume but the web app never emitted them.
  • A duration calculation bug in the TTS queue used /24 instead of /48 (24kHz × 2 bytes = 48 bytes/ms), causing 2x timing errors for queued buffers.

Fix: orchestrator now calls stopPlayback() on both suspend and resume, web emits lifecycle events, and the duration math is corrected. Three files touched, zero-risk change.

Auto-submit for mobile chat

Mobile keyboards don't reliably fire Enter/submit events. Added an 8-second idle timer — if the user stops typing for 8 seconds, the message submits automatically. Only active on native mobile and mobile web; desktop is unaffected. Timer resets on every keystroke.
